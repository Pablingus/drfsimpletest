# Django REST Framework Practice Project

This project was created as a **practice exercise** while learning how to build REST APIs with **Django** and **Django REST Framework**.

The project follows the concepts and implementation demonstrated in the tutorial by **Fazt**, with the code recreated locally as part of my learning process.

## About the Project

The purpose of this project is to gain practical experience with backend development and REST APIs using Python and Django.

Through this project, I practiced concepts such as:

* Django project and application structure
* Django models
* Django REST Framework
* Serializers
* API views
* URL routing
* HTTP requests
* CRUD operations
* JSON responses
* Database interaction through Django's ORM

## Technologies Used

* Python
* Django
* Django REST Framework
* SQLite
* HTML/CSS
* Git & GitHub

## Learning Purpose

This repository is primarily a **learning project**. It was created by following an existing tutorial rather than being an original application developed entirely from scratch.

The purpose of keeping it on GitHub is to document my progress while learning Python backend development and to have a reference that I can return to when working on future projects.
